agentic-3d

前沿模型写代码或调用工具，生成或重建可进仿真的三维物体与场景，以及评测这件事的基准。以仿真物理与 Real2Sim 为目标的归 robotics-simulation。

一类工作用程序或工具调用生成可仿真的物体和房间，一类评测编码 agent 能否把动态场景写成图形程序，一类按真实文字 / 图 / 视频参考交付可编辑 Blender 工程并跨模型评测，一类把参考视频里的运动换成经解析解对照与独立实现复核的物理求解再渲染，一类把对话 agent 做进 Blender、按提示多步建模与画纹理的创作工具，一类让 agent 经 MCP 调生成模型出 3D 资产、再驱动 DCC 与游戏引擎落地的技能包，一类给 LLM 写带关节物体用的省 token 建模库与程序数据集。数字都是作者自报，房间重建没有对照数字，创作工具、技能包与建模库没有生成质量评测。

  • Articraft：LLM 对着领域 SDK 写程序生成铰接资产；Articraft-10K 有 245 个类别、超过 1 万个资产。（自报）
  • 4DCodeBench：编码 agent 看视频写图形程序重建动态场景；18 个 agent、200 个任务，运动重建是短板。（自报）
  • Artisan：设计、编码、审查三个智能体加物理验证生成铰接资产；GPT-6 Astra 下单关节碰撞率 1.7%。（自报）
  • AHa-3D：GPT-6 Astra 用工具把室内视频收成 Blender 里可编辑的场景；未给对照数字。（自报）
  • BlenderWorld：13 个前沿模型在 223 个任务上按真实参考交付 Blender 可编辑工程；GPT-6 Astra 融合分 79.9、全 rubric 通过率 42.2%。（自报）
  • Mixar：Blender 5.2 分支内置对话 agent，对场景规划并执行建模、纹理、材质、UV 等多步操作，另有文生 / 图生 3D；AI 后端闭源托管，未给评测数字。（自报）
  • PhysAg3D：3D 生成器出整体网格，视觉语言 agent 搭关节或柔性区域并绑定到可见表面，按渲染与 MuJoCo 执行结果修复；50 个真实物体上全部动作稳定完成 88.0%，最强基线 42.0%。（自报）
  • Video 2 Physics：coding agent skill，测量视频运动、换成声明并基准检验过的物理求解，由独立实现复核后烘焙进 Blender；五个示例中独立求解器吻合到 1e-13 量级。（自报）
  • Scenario Agent Skills：agent 经 Scenario MCP 调 Meshy、Rodin、Sparc3D 等生成 3D 模型、世界与可行走房间，再用技能驱动 Blender、Unreal、Unity、Godot 落地；只验证工具能跑，未评测产出。（项目 README，无评测）
  • sand3d：Blender bpy 之上按名引用零件、声明关节、导出 URDF / USD 的建模库，附五个程序化数据集；每个零件中位 token 数 Blender Python 是它的 4.0 倍、Articraft SDK 2.0 倍，没有生成质量评测。（自报）

agentic-robotics

冻结的前沿模型当 agent、在模型外写代码技能 / 程序 / harness 来驱动机器人操作的工作，以及评测这类 agent 的 benchmark。

13 个系统让 agent 从执行反馈中把经验沉淀成模型外的技能、程序、记忆或 harness，7 个 benchmark 评测这类 agent，其中 RoboDojo 与 BiGym 2.0 同时评 VLA 等学习策略，EmbodiedLab 让 agent 自己做实验测出隐藏物理量，另有一个把 LLM agent、code-as-policy 与 VLA 接到同一套真机与仿真接口上的评测框架；另有一项实证研究比较前沿模型直接出动作、在 agent 会话里出动作、监督学习策略三种用法；一个工作反过来不动 harness，用教师轨迹 SFT 加多轮 RL 训练 harness 里的小规划器本身；另一个也在 harness 里训练模型本身，用仿真内 SFT 加 GRPO、训练全程不碰真机数据；第三个只给 4B 模型低层感知与运动原语、不调 VLA，RL 时用读仿真特权状态的评论家给每次请求分配 credit。常见评测是 RoboDojo、LIBERO-Pro、BEHAVIOR-1K、RoboCasa。另有一个把 Agent as Policy、自动研究、仿真任务构建、Real2Sim 与动作生成五类工作流打包成每项千行以内的技能包，配首方工具压低 token 成本。另有一个统一 harness 把 Codex / Claude Code 等运行时接到仿真与真机、不给深度与任务检查器反馈，用它比较模型代际与家族：开放权重模型在 RoboDojo 上超过官方公布的 GPT-6 Astra 结果，同一模型换其它 harness 分数低得多。只有一个系统的分数由 benchmark 方在隐藏种子上复评，其余都是自报。

  • ASPIRE AMD 🔶：按执行 trace 修 code-as-policy 程序，验证过的修复进技能库；Claude Opus 5.5 下 LIBERO-Pro 平均 99%。（自报）
  • Harness VLA：规划器从固定原语库选调用，冻结 VLA 只做局部接触，探索成功的调用序列存进任务记忆；LIBERO-Pro 同一冻结 π0.5 50.0% → 82.4%（Claude Code），RoboCasa365 30.0% → 57.2%。（自报）
  • HarnessPAI：一次 rollout 内程序固定，多次 rollout 之间改代码；不重训时 LIBERO-PRO 比 π0.5 高 61.6 个点，并报 96.5%。（自报）
  • RoboDojo：42 个仿真加 18 个真机任务的操作策略 benchmark，公开排行榜设 agent 赛道；2026-10-17 仿真榜前两名 WorldScape-R²SI 46.58、EmbodiedEvo 45.08 都在 agent 赛道。（自报）
  • Embodied Agent Arena：10 个前沿 VLM agent 用同一套最小 harness 测几何、空间、规划、操作与可供性五类能力，共 1,000 例；GPT-6 Astra Planning 80.3%、Claude Opus 5.5 Manipulation 47.8%，157 个 Planning 任务有 15 个十个模型全失败。（自报）
  • EmbodiedEvo：在 Playground 场景把物理反馈写成代码 Skills 与 Lessons，冻结后在未见场景执行；RoboDojo-Sim 自跑 Score 44.48、SR 37.82%。（自报）
  • EmbodiedRSI：冻结 VLA 外的 harness 按信息增益与实验成本选下一次物理实验；RoboCasa365 77.0%，真机 SmolVLA 46.0% → 71.3%。（自报）
  • RoboQuest：10 个需靠物理交互取证的移动操作 benchmark；最好的 GPT-6 Astra 成功率 23.2%，失败主要来自缺证据。（自报）
  • RobotWorld：多模态 agent 只用公开的观测与动作工具，在仿真里控制 18 种具身完成 84 个任务，成功由 agent 看不见的评测器判定；项目页未给总分。（自报）
  • Robota-Embed：视觉、语言、动作统一嵌入，检索未来经验片段作上下文；冻结 GPT-6 Astra 加演化出的任务内记忆，ManiSkill 五任务成功率 24% → 68%，策略 token −43.7%。（自报）
  • SenseNova-RoboRSI AMD ✅：冻结权重，用执行反馈改 Harness；RoboDojo-Sim 平均分 60.08、成功率 54.17%，称正在提交官方榜。（自报）
  • WorldScape R²SI：内层 agent 调 Skill 执行，外层 agent 复盘修 Skill 并用执行记录训练动作模型；称 RoboDojo 总榜第一，未给分数。（自报，公司发布稿）
  • Embodied First Exam：coding agent 写代码控制仿真机器人的 benchmark，31 个 suite、1,090 个任务；核心 449 题上 Codex + GPT-6 Astra 32.7%，privileged 75.5% 而 standard 33.8%。（自报）
  • PhysicalRSI 1.0：基座改写 harness 生成多个变体、按仿真表现选优继承，π₀.₅ 作为技能之一；RoboDojo-Sim 官方榜 Score 36.27、SR 31.38%。（自报）
  • HexaShell：coding agent 只用一条命令行与三路 RGB 驱动机器人，失败后由第二个 agent 写或修工具；RoboDojo 隐藏种子官方评测 SR 46.9%、进度分 53.2。（第三方，RoboDojo 官方评测）
  • Astranomy：GPT-6 Astra 当原生机器人策略的三种用法；RoboLab-120 上 Codex 会话里的 Agentic Policy 74.8%，每个成功回合约 $36.40。（自报）
  • RoboDoctor：agent 审查、修正或接管冻结 PrismWAM 的动作，按 Warmup 分数选控制方式，再更新干预经验；RoboDojo 54 个任务本地 Refinement 57.10 / 49.44%。（自报）
  • Inspect Robots：把前沿 LLM agent、code-as-policy 与 VLA 接到同一套真机与仿真接口上评测，每次运行留可离线重打分的日志；alpha 阶段，未报评测结果。（自报）
  • RoboRSI AMD ✅：四个 agent 按任务–技能树执行与改技能，失败定位到最早出问题的节点、只改那一支；LIBERO-PRO 297/600（49.5%）对 OpenETA 231/600（38.5%），真机 104 轮家庭清理。（自报）
  • AgenticRoboRL AMD ✅：harness 与 VLA 不动，SFT 加多轮 RL 训练 9B 规划器；RPent / LIBERO-PRO 18.1% → 71.0%，不用外部记忆，同表 Codex（GPT-5.5）带记忆 72.1%。（自报）
  • BiGym 2.0：G1 人形 20 个家务任务，学习策略与冷启动 coding agent 程序走同一全身控制器；九任务均值 π0.5 75%、GPT-6 Astra 65%、Claude Opus 5.5 61%，agent 领先双手 reach、搬运类多数失败。（自报）
  • EmbodiedLab：agent 操作 Franka 自己做 30 个物理与化学实验测隐藏量；原生控制下 Claude Opus 5.5 43.3%，加感知与规划工具最多 +10 点，75–100% 的失败出在与仪器交互。（自报）
  • RoboSkills：五类机器人 agent 工作流打包成每项千行以内的技能包，配首方工具；Agent as Policy 在完整 RoboDojo 上 40.5%，对官方 GPT-6 Astra 22.48%，同任务成本为 Claude Opus 5.5 的 7%。（自报）

robotics-rl

无示教机器人强化学习里，任务配置 / 起始状态怎么采样、奖励从哪来（稀疏或二值奖励、学到的价值模型）的工作，以及评测这类价值模型的 benchmark。

三个工作按成功率调整采样，只用稀疏或二值奖励，其中一个是在另一套仿真器里对 AlphaNIST 的独立复现；另一个让策略梯度穿过学到的世界模型，训练人形全身运动跟踪，另一个改为穿过可微仿真器的精确梯度、不学世界模型，另有一份社区复现汇总把同一方法在单张消费级 GPU 上几小时复现到接近原回报，还有一个独立重实现把它扩到三台人形、用形态向量共享世界模型与策略，回报与各自专家差 0.02 以内，另一个移植到灵巧手 in-hand 操作但没有给数字；还有一个改起始状态采样，把 15% 的重置放到评估失败点之前，单张 RTX 4090 平均 2.94 分钟到回报 0.82。奖励的另一来源是学到的价值模型：一个仿真加真机 benchmark 用私有测试集评测它们判断任务成功与进度的能力，最好的零样本模型 Overall 约 60 分；另一个不训练、只提示 VLM 先描述轨迹再按成功标准打进度分，在自建 benchmark 上超过后训练的价值模型，并在真机在线 RL 里当奖励。另有一个无示教配方训练 16-DoF LEAP 手的 in-hand 6D 位姿到达，用生成抓取数据集采样目标与初始状态、加自适应摩擦课程，再用残差安全滤波器把真机掉落从 16 降到 4。此前的训练类工作数字都来自仿真、真机只有演示；这份工作给出 4,800 个目标的真机评测；汇总里的复现未经独立复核。全部是自报。

  • SGS：PPO 外按成功率加权采样任务配置；1M 并行环境时 ANYmal D 全地形 0.73、Franka 螺母装配 0.70，均匀采样约 0。（自报）
  • AlphaNIST：二值奖励、无示教学 NIST 装配板 20 个任务；共享策略训练成功率 98.2%。（自报）
  • AssembleNIST AMD ✅：在 MuJoCo 里独立复现 AlphaNIST，起始状态用 SGS 采样；8,192 并行环境 10K 迭代评测成功率 98.4%。（自报）
  • SuperMimic AMD ✅：策略梯度穿过与策略同步训练的世界模型，不穿过仿真器；1 张 H100 训练 3 小时超过 SONIC（约 21,000 GPU 时）的归一化回报，2 GPU × 9.8 h 时 129,514 条动作零失败。（自报）
  • Awesome SuperMimic：汇总 SuperMimic 的 33 个社区实现；单张 RTX 5090 / A6000 / PRO 6000 上 1.3–4 小时在 40 条 LAFAN1 动作上复现到归一化回报 0.824–0.853，观测设置不同、结果不可直接比。（上游自报，列表未独立复跑）
  • MorphMimic：独立重实现 SuperMimic 并加 125 维形态向量，G1 / X2 Ultra / T2 共享世界模型与策略；128,786 条动作上共享模型回报与专家差 ≤ 0.018，只在 G1 上训的专家换到 T2 存活不到 3%。（自报）
  • BlinkMimic：在 SuperMimic 的可微世界模型训练上加评估失败点引导重置、半隐式世界模型与镜像增广，一个策略跟 40 条 LAFAN1 动作；单张 RTX 4090 三个种子平均 2.94 分钟到回报 0.82，InstantTrack v1.2 5.89 分钟，SuperMimic 估计约 41 分钟；只有仿真。（自报）
  • Dex SuperMimic：把 SuperMimic 的世界模型三阶段训练移植到 Wuji 灵巧手，做 in-hand 立方体重定向与转笔；只有仿真演示与 checkpoint，没有数字。（自报）
  • RoboValue：评测价值模型（从观测与指令判断任务成功与进度）的 benchmark，15 个仿真加 20 个真机任务，测试集私有、由团队代跑；Zero-Shot 最好 RoboMeter-4B 60.05、VLAC-2B 最低 29.95，RoboReward-4B / 8B 价值一致性为 0。（自报）
  • DexSafe：无人类数据训练 LEAP 手的 in-hand 6D 位姿到达，目标与初始状态取自生成抓取数据集、加自适应摩擦课程，零样本上真机；4,800 个未见目标上状态策略达 95.2%，残差安全滤波器把掉落 16 → 4、成功率仍有 91.5%。（自报）
  • D&A：VLM 先描述轨迹、再按明确成功标准打进度分，纯提示不用机器人数据；D&A-Bench Kendall τ 0.67 对 Robometer 0.56，GPT-6 Astra 底座 0.790；DSRL 在线 RL 约 90 分钟把 π0 放水果成功率 10% → 100%，用 TOPReward 5%。（自报）
  • ∇Mimic（NablaMimic）：策略梯度直接穿过可微仿真器的精确接触梯度、不学世界模型，一个策略跟 40 条 LAFAN1 动作；README 称 8 分钟到回报 0.82、约 0.91 收敛（论文写 20 分钟到 0.82、1.8 h 到 0.874）。（自报）

robotics-simulation

以机器人仿真本身为研究对象的工作：物理引擎与仿真平台、从真实观测重建或校准仿真场景与物理参数（Real2Sim）、在仿真里批量生成合成数据的流水线，以及检验仿真评测或仿真数据能否代替真机的工作。只在仿真里训练或评测某个策略、只发布仿真任务集而不检验与真机一致性的不算；学到的视频世界模型归 video-world-models。

十二个工作：四个平台，一个是面向触觉与软体接触的物理引擎，一个把 3DGS 场景重建、LLM 生成场景、合成数据与 benchmark 放在一起，一个让同一任务配任意臂与末端、内置遥操作与仿真触觉并发布示范数据，一个是 Isaac Lab 上的桌面机械臂–积木受控框架、用 RL 技能加 TAMP 自动生成示范并按 PDDL 判成功；三条 Real2Sim 流水线分别从一张图、人类示范视频和 3D / 4D 采集重建可进仿真的场景，其中一条由编码 agent 调工具并在仿真器里自查；一个 Real2Sim 数据引擎把第一人称视频与动捕的人手示范，用生成式重定向批量转成 223k 条带接触力标注的灵巧手轨迹；一个工具让人和编码 agent 对着视频调多物理仿真的求解器与参数；一条把仿真数据生成分布当优化对象、用元梯度挑参数再与少量真机示范共训的流水线（四个真机任务全任务成功 52/80 对均匀生成 30/80，专家手调 56/80）；一个带仿真与真机一致性标定的 benchmark；一个在程序化生成的 1,000 个家庭里合成 300 小时第一人称视觉–语言–全身运动数据、再用生成器与 RL 跟踪器上真机的流水线。三个工作量了仿真与真机的一致性：单图重建场景里 π0.5 的仿真与真机成功率 Pearson r = 0.887，benchmark 里一个基座模型的成功率相关 0.74，平台的 2×2 表里仿真数据训的策略仿真 0.80、真机 0.83；三者各只用一个基座模型标定。HALO 与 ToyBlocks 又各报了自己系统在仿真与真机的成功率（HALO 单任务 91% / 91%，ToyBlocks 原子技能 80.0% / 81.1%、分层拼写 55.5% / 50.0%）。Real2Sim 的物理是否与真机一致多为定性比较，物理引擎没有给数字。全部是自报。

  • RoboSnap：从一张 RGB 图重建可进仿真的场景，约 20 分钟一个；合成数据与真机数据共训让 π0.5 / π0 真机平均提高 9.0 / 13.4 点，只用真机数据微调的 π0.5 仿真与真机成功率 Pearson r = 0.887。（自报）
  • X2Real：Isaac Lab-Arena 上 10 个能力维度、44 个分层长程任务的仿真 benchmark；用 Wall-OSS-0.5 标定，仿真与真机进度分相关 0.84、成功率 0.74，精度任务有明显 real2sim gap。（自报）
  • Video to Data (V2D)：人类示范视频 → 重建网格与 6-DoF 位姿 → 人手重定向到灵巧手 → Isaac Lab 里按接触力旋量奖励训 RL；自建 4,739 任务中评 1,831 个平均 82.12%，真机只有演示。（自报）
  • Genie Sim：3DGS 重建、LLM 生成场景与评测配置、5,140 个资产与 1 万小时以上合成数据的仿真平台；8 个任务的 2×2 表里仿真数据训的 π0.5 仿真 0.80 / 真机 0.83，真机数据训的 0.75 / 0.75。（自报）
  • RoboSimStudio：求解器、接触模型与物理参数显式可调的多物理仿真工具；编码 agent 约一小时从手机视频搭出双臂擦拭仿真，GaP 在仿真里 14 轮把擦除面积 0% → 100% 后上真机，仿真与真机一致性只做定性比较。（自报）
  • SceneAgent：编码 agent 把 3DGS / LiDAR / 4D 视频转成 Isaac Lab 场景并在仿真器里自查修错；GraspClutter6D 上 F1@1cm 最高 60.75%（SimFoundry 6.9%）；只用仿真示教微调的 VLA 真机 88%，但示教从 40 条加到 4k 条时真机成功率 48% → 12%。（自报，代码未放出）
  • Project SuperDex：接触优先物理引擎、机器人 SDK、资产编辑器与 Gymnasium 式 RL 接口组成的灵巧操作仿真平台；README 不给数字，RL 接口为早期预览。（自报）
  • MetaGenSim：把仿真器的数据生成分布作为优化对象，用元梯度训 rater 网络挑高价值参数，再与 10 条真机示范共训；四个真机任务全任务成功 Diffusion Policy 58/80、π0.5 微调 52/80，均匀生成 23/80 与 30/80，专家手调 57/80 与 56/80。（自报）
  • GNR（Generative Neural Retargeting）：第一人称视频与动捕的人手示范重建进 SuperDex，域随机化物体位姿、物理与几何后用流匹配重定向；360k 条增广示范里 DIAL-MPC 解出 95k，GNR 再解出 127k，合计 223k 条、3.3k 个几何体，总 CPU 成本降 2.62×；未检验与真机一致性。（自报）
  • DexSuite：Genesis 上 30 个任务可配 10 种臂与 12 种末端，内置遥操作与仿真触觉，16 个任务–具身对 benchmark 与 4,700 条示范；六个基线最好成功率夹爪 / Allegro 手 Pick & Place 66% / 76%、Stack 16% / 9%，Toast Bread 0%；未检验与真机一致性。（自报）
  • HALO：程序化生成的 1,000 个家庭里合成 300 小时第一人称视觉–语言–全身运动数据；Qwen3.5-2B 冻结编码器加 DiT 生成 5 秒运动计划、50 Hz RL 跟踪器执行，Qwen3.6-35B-A3B 在机上拆子任务；六个技能仿真与真机各 91%（真机 360 次），长程组合 69% / 70%。（自报）
  • ToyBlocks：Isaac Lab 上的桌面机械臂–积木受控仿真框架，RL 技能与 TAMP 自动生成示范、PDDL 目标自动判成功；发布 85,336 条示范（1,600 小时、1.44 亿帧）与 ManiFlow-tb / Molmo2-4B-tb；ManiFlow 原子技能仿真 80.0% / 真机 81.1%，分层拼写 55.5% / 50.0%。（自报）

video-world-models

构建可交互、长程生成的视频世界模型的工作：其数据整理、latent 表示、因果训练与蒸馏方法，以及衡量生成是否跟随控制信号、能否在想象中替代真机评测策略的评测。

八个构建工作分别给出数据与训练配方、可在想象中闭环评测策略的动作条件模型、按下游策略回报训练世界模型的目标、用一套条件化同时接入力、相机、手与机器人姿态的统一动作接口、一个原生同时生成环境音与人物对话、由 Gemini 在环实时拆步骤推进场景的闭源预览、一个用统一模型接多轮文本与键盘 / 相机轨迹、分段因果生成的开放模型、一个在三维体素 latent 里预测、可从任意视角渲染并同时预测触觉的动作条件模型，以及一个在冻结视频骨干上加 LoRA 把结构视频渲成成品视频的少步渲染器；两个 benchmark，一个拿同一段动作下的预测视频与真机执行比、长回合上各模型分数明显下降，一个是自建的 280 例交互能力人工成对评测。构建类工作没有共同的定量对照：SolarWM 只给定性 rollout，Ctrl-World 的 README 不给数字，DRILL 只在自己的五个仿真器上对照像素目标，Genie 4 只有博客演示、一个数字都没给，Hy-Nomas 只在自建 benchmark 上比人工胜率，3D World Simulator 只在自建 ALOHA 任务与 Deform360 上对照 2D 视频与 3D 粒子基线。全部是自报。

  • SolarWM：多源视频整理成 1.43M 段帧对齐片段，同一套三阶段配方套在四种 5B–33B 骨干上，蒸馏出 16 fps、4 步采样的因果模型，最长连续生成 60 分钟；只有定性 rollout。（自报）
  • Ctrl-World AMD ✅：DROID 上训练、基于 Stable Video Diffusion 的动作条件世界模型，让 π0.5-DROID 在想象中闭环 rollout 评测指令遵循；H100 每个 1 秒交互步约 5 s，README 不给评测数字。（自报）
  • WorldOracle：同一初始观测与动作轨迹下比预测视频与真机执行，335 条、约 40% 是失败段；WorldOracle-SV 从 30 秒到全长，GE-Sim 2.0 73.86 → 63.33，Cosmos 3 53.99 → 26.60。（自报）
  • DRILL：把世界模型的后训练目标换成想象 rollout 内 GRPO 更新后的策略回报；π0-3B 上五个仿真器平均成功率比 WMPO 高 13.1、比 RLVR-World 高 7.9 点，单步像素 MSE 反而高 17%。（自报）
  • UniAction：异构动作表示成带时空坐标的稀疏元素、映射进视频模型的位置空间，一个模型统一做动作条件；四种动作的动作跟随都高于 VACE 与 Cross-Attn，联合训练也高于单动作专家（力 0.763 vs 0.544）。（自报）
  • Genie 4：键盘加文字 prompt 实时操控场景，原生同时生成环境音与人物对话，Gemini 3.8 Flash 在环拆步骤、Gemini 4 Argon 拆任务喂字幕；博客未给任何数字，闭源研究预览。（自报，公司发布稿）
  • Hy-Nomas：8B 扩散骨干，一个模型接多轮自由文本与键盘 / 相机轨迹控制，滑窗历史加分段因果注意力；自建 Hy-Nomas-Bench 280 例人工成对评测，多轮文本指令遵循 65.0% / 75.0% 胜，空间记忆对 Genie 3 净负 16.7 点。（自报）
  • 3D World Simulator：粒子–体素自编码器加 3D U-Net latent 动力学，解码成 3D Gaussian 与触觉粒子，RTX 5090 上 50+ FPS；六个 ALOHA 任务 200 步开环 PSNR 23.24 对 Robot4DGen 20.59、场景 Chamfer 7.72 对 10.43；模型内与真机的策略成功率相关性与生成数据训练策略只给图。（自报）
  • SolarRenderer：冻结 MiniMax-H3 33B 加两个 LoRA，把结构视频渲成成品视频、四步采样；208 例泛化集上 Elo 1441 第一，11 种训练中未见的结构表示可用。（自报）
