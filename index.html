action-conditional-world-models

以机器人动作为条件、预测执行后观测（像素、隐空间或三维表示）的世界模型：模型构建与目标域后训练（含失败与反事实数据），动作后果保真的评测（动作跟随、同起点成败区分与失败乐观、长时程漂移），以及把它当策略评测器、数据生成器或 RL 环境时与真实环境是否一致。文本、键盘或相机控制的通用交互视频生成归 video-world-models；输出机器人动作的世界动作模型按 robot-policy 判定，它的世界模型模式在外部给定动作下被评测时两边都挂；在世界模型里训练策略的 RL 配方按 robot-policy 或 robotics-rl 判定，对世界模型本身有贡献时两边都挂；只把学得动力学当策略梯度通道、不评预测本身的不算。

  • 构建动作条件模型：DROID 上的 Stable Video Diffusion 模型让 π0.5 在想象中闭环评测；跨人与多种机器人的第一人称模型用相机位姿与投影骨架当动作接口，在 RoboTwin 上给五个 π0.5 checkpoint 排序 r = 0.984；把力、相机、手与机器人姿态统一成稀疏动作元素的条件化接口；三维体素 latent 里的动作条件模型；冻结 V-JEPA 隐空间里的动作条件模型，预测误差随算力服从幂律。
  • 世界动作模型的世界模型一侧：以给定动作预测未来，补失败 rollout 后失败子集 PSNR 19.51 → 25.92；用反事实分支训练局部前向动力学模型，同起点 16 条分支认出实际结局 21.1% → 71.3%。
  • 后训练：按想象 rollout 内的下游策略回报后训练（像素 MSE 反而高 17%）；只换数据，用执行验证的反事实回放修失败不敏感（LIBERO-Goal value optimism 79.55% → 30.17%，四次独立微调仍有 30–43%）。
  • 评测：同一动作下对照真机执行、约 40% 是失败段，长回合各模型分数明显下降。
  • 当 RL 环境并回真实环境验收：World-Gymnast 在真机上超过在 SIMPLER 里做 RL，DRILL 在五个仿真器上验收，WoVR+ 在 RoboTwin 回 simulator 与六个真机任务上验收；同一世界模型只把探索噪声改成按动作块共享就让 adjust_bottle 成功率差 17.6 点。
  • 当闭环模拟器与数据生成器：从动作条件视频模型的潜变量解码本体状态、加逐帧 VLM 世界裁判给成功信号，并蒸馏到秒级 rollout；闭环 episode 一致准确率 0.81，用它过滤行为克隆数据使真机三任务平均成功率 0.417 → 0.567。
  • 失败保真只在 LIBERO、DROID 与 Franka 上量过，口径各异（value optimism、visual optimism、PSNR、分支辨识）；RoboTwin 上只有 WoVR+ 量过 200 帧自回归的保真衰减，没有工作报失败乐观率。
  • 全部是自报。
  • Ctrl-World AMD ✅：DROID 上训练、基于 Stable Video Diffusion 的动作条件世界模型，让 π0.5-DROID 在想象中闭环 rollout 评测指令遵循；H100 每个 1 秒交互步约 5 s，README 不给评测数字。（自报）
  • WorldOracle：同一初始观测与动作轨迹下比预测视频与真机执行，335 条、约 40% 是失败段；WorldOracle-SV 从 30 秒到全长，GE-Sim 2.0 73.86 → 63.33，Cosmos 3 53.99 → 26.60。（自报）
  • DRILL：把世界模型的后训练目标换成想象 rollout 内 GRPO 更新后的策略回报；π0-3B 上五个仿真器平均成功率比 WMPO 高 13.1、比 RLVR-World 高 7.9 点，单步像素 MSE 反而高 17%。（自报）
  • 3D World Simulator：粒子–体素自编码器加 3D U-Net latent 动力学，解码成 3D Gaussian 与触觉粒子，RTX 5090 上 50+ FPS；六个 ALOHA 任务 200 步开环 PSNR 23.24 对 Robot4DGen 20.59、场景 Chamfer 7.72 对 10.43；模型内与真机的策略成功率相关性与生成数据训练策略只给图。（自报）
  • CureWM：不改架构与损失，按扰动族 × 强度改写成功示范的动作、实际执行判成败后混训，修 Cosmos Policy 与 Ctrl-World 的失败不敏感；LIBERO-Goal value optimism 79.55% → 30.17%、AUROC 0.495 → 0.743，四次独立微调 30.2–43.0%；真机 Franka visual optimism 27/30 → 10/30。（自报）
  • Ropedia W0：相机位姿加投影运动学骨架当跨具身动作接口；当策略评测环境，RoboTwin 2.0 五个 π0.5 checkpoint Pearson r = 0.984，真机 G1 三个 Ψ0 checkpoint 加专家遥操作 r = 0.996；5B 权重 CC BY-NC 4.0，后训练代码未放出。（自报）
  • UniAction：力、相机运动、手部与机器人姿态统一成带时空坐标的稀疏动作元素做条件化；四种动作的动作跟随都高于 VACE 与 Cross-Attn，联合训练也高于单动作专家（力 0.763 vs 0.544）。（自报）
  • OpenWAM（Stanford）：局部上下文 FDM 只看当前观测、proprio 与给定动作轨迹预测未来；用 LIBERO-Long 反事实分支训练后，同起点 16 条分支认出实际结局 21.1% → 71.3%，RGB MSE −34.5%；FDM checkpoint 未发布。（自报）
  • FACT：未来视频与进度值以 teacher-forced 的干净动作为条件，失败 rollout 只监督后果；失败子集单块 PSNR 19.51 → 25.92、成功子集不变；只测一个 48 步块，价值头的成败区分只有图。（自报）
  • RoboJEPA：冻结 V-JEPA 2.1 隐空间里的动作条件世界模型（22M–8B，12 种具身 23 个数据集）；预测误差随训练算力服从二阶幂律，按单张目标图像规划控制真机 Franka。（自报）
  • World-Gymnast：在 600M 动作条件世界模型 WorldGym 里对 OpenVLA-OFT 做 GRPO、GPT-4o 判成功；Bridge 真机 AutoEval 四任务 58 / 62 / 72 / 78%，在 SIMPLER 里做 RL 为 34 / 74 / 32 / 40%。（自报）
  • WoVR+：Wan2.2-TI2V-5B 加几何控制分支的多视角动作条件世界模型，按动作块共享探索噪声做 GRPO，RoboTwin 回 simulator 评测：adjust_bottle / click_bell 多视角随机初态 70.70 / 72.66% → 91.80 / 93.75%（Ctrl-World 76.56 / 78.52%），同一世界模型下逐 token 噪声 74.22%；世界模型内与真机成功率 Pearson 0.97；真机六任务 39.2% → 55.8%。（自报，未报告多 seed）
  • GE-Sim 2.0：在 Genie Envisioner 动作条件视频模型上用数千小时真机数据重训，加视频潜变量解码本体状态、逐帧 VLM 世界裁判与 DMD2 少步蒸馏，单张 H100 约 2.3 s rollout；2B 参数登上 WorldArena 总榜第一，六任务 head-view PSNR 23.05 对 Ctrl-World 19.09，闭环 episode 一致准确率 0.81，过滤 BC 后真机平均 0.417 → 0.567。（自报）

agentic-3d

前沿模型写代码或调用工具，生成或重建可进仿真的三维物体与场景，以及评测这件事的基准。以仿真物理与 Real2Sim 为目标的归 robotics-simulation。

  • 用程序或工具调用生成可仿真的物体和房间。
  • 评测编码 agent 能否把动态场景写成图形程序；按真实文字 / 图 / 视频参考交付可编辑 Blender 工程并跨模型评测。
  • 把参考视频里的运动换成经解析解对照与独立实现复核的物理求解再渲染。
  • 创作工具与技能包：做进 Blender、按提示多步建模与画纹理的对话 agent；让 agent 经 MCP 调生成模型出 3D 资产、再驱动 DCC 与游戏引擎落地的技能包。
  • 给 agent 用的建模库与引擎：写带关节物体的省 token 建模库与程序数据集；写场景程序、渲染后看图修改的无头 3D / VFX 引擎；把 AI 生成的 Three.js 在设备上即时编译到 Android / iOS / WebXR 原生引擎、并给 agent 提供无头渲染与 MCP 验证的跨平台运行时。
  • 数字都是作者自报；房间重建没有对照数字，创作工具、技能包、建模库、渲染引擎与跨平台运行时没有生成质量评测。
  • Articraft：LLM 对着领域 SDK 写程序生成铰接资产；Articraft-10K 有 245 个类别、超过 1 万个资产。（自报）
  • 4DCodeBench：编码 agent 看视频写图形程序重建动态场景；18 个 agent、200 个任务，运动重建是短板。（自报）
  • Artisan：设计、编码、审查三个智能体加物理验证生成铰接资产；GPT-6 Astra 下单关节碰撞率 1.7%。（自报）
  • AHa-3D：GPT-6 Astra 用工具把室内视频收成 Blender 里可编辑的场景；未给对照数字。（自报）
  • BlenderWorld：13 个前沿模型在 223 个任务上按真实参考交付 Blender 可编辑工程；GPT-6 Astra 融合分 79.9、全 rubric 通过率 42.2%。（自报）
  • Mixar：Blender 5.2 分支内置对话 agent，对场景规划并执行建模、纹理、材质、UV 等多步操作，另有文生 / 图生 3D；AI 后端闭源托管，未给评测数字。（自报）
  • PhysAg3D：3D 生成器出整体网格，视觉语言 agent 搭关节或柔性区域并绑定到可见表面，按渲染与 MuJoCo 执行结果修复；50 个真实物体上全部动作稳定完成 88.0%，最强基线 42.0%。（自报）
  • Video 2 Physics：coding agent skill，测量视频运动、换成声明并基准检验过的物理求解，由独立实现复核后烘焙进 Blender；五个示例中独立求解器吻合到 1e-13 量级。（自报）
  • Scenario Agent Skills：agent 经 Scenario MCP 调 Meshy、Rodin、Sparc3D 等生成 3D 模型、世界与可行走房间，再用技能驱动 Blender、Unreal、Unity、Godot 落地；只验证工具能跑，未评测产出。（项目 README，无评测）
  • sand3d：Blender bpy 之上按名引用零件、声明关节、导出 URDF / USD 的建模库，附五个程序化数据集；每个零件中位 token 数 Blender Python 是它的 4.0 倍、Articraft SDK 2.0 倍，没有生成质量评测。（自报）
  • vork：给 agent 用的无头 3D / VFX 渲染引擎，agent 写场景程序、渲染后看图改；NVIDIA L4 上 1080p 静帧比 EEVEE 快 1.38–1.66×、240 帧短片 1.14–2.32×，路径追踪慢 1.99–5.81×，作者声明不是等质量对比。（自报）
  • Three-Live：Google 的 AI-first 原生 3D / CAD / XR 运行时，在设备上的沙箱 Rust VM 里即时编译 LLM 写的 Three.js，渲染到 Android（Filament / Jetpack XR）、iOS / visionOS（RealityKit）与 WebXR；给 agent 提供无头四视图渲染、场景校验与 MCP 服务；Beta，未评测生成质量。（项目 README，无评测）

agentic-robotics

冻结的前沿模型当 agent、在模型外写代码技能 / 程序 / harness 来驱动机器人操作的工作，以及评测这类 agent 的 benchmark。

  • 让 agent 从执行反馈中把经验沉淀成模型外的技能、程序、记忆或 harness 的系统。
  • 评测这类 agent 的 benchmark：RoboDojo 与 BiGym 2.0 同时评 VLA 等学习策略，EmbodiedLab 让 agent 自己做实验测出隐藏物理量；另有把 LLM agent、code-as-policy 与 VLA 接到同一套真机与仿真接口上的评测框架。
  • 一项实证研究比较前沿模型直接出动作、在 agent 会话里出动作、监督学习策略三种用法。
  • 不动 harness、训练 harness 里的模型本身：用教师轨迹 SFT 加多轮 RL 训练小规划器；用仿真内 SFT 加 GRPO、训练全程不碰真机数据；只给 4B 模型低层感知与运动原语、不调 VLA，RL 时用读仿真特权状态的评论家给每次请求分配 credit。
  • 技能包：把 Agent as Policy、自动研究、仿真任务构建、Real2Sim 与动作生成五类工作流打包成每项千行以内的技能，配首方工具压低 token 成本。
  • 统一 harness 把 Codex / Claude Code 等运行时接到仿真与真机、不给深度与任务检查器反馈，用它比较模型代际与家族：开放权重模型在 RoboDojo 上超过官方公布的 GPT-6 Astra 结果，同一模型换其它 harness 分数低得多。
  • 常见评测是 RoboDojo、LIBERO-Pro、BEHAVIOR-1K、RoboCasa。
  • 只有一个系统的分数由 benchmark 方在隐藏种子上复评，其余都是自报。
  • RAX：coding agent 在线探索学任务，再编译成脱离 agent 运行的程序；未见布局平均成功率随探索 4 → 128 回合从 25% 升到 79%，编译后执行快 100× 以上。（自报）
  • ASPIRE AMD 🔶：按执行 trace 修 code-as-policy 程序，验证过的修复进技能库；Claude Opus 5.5 下 LIBERO-Pro 平均 99%。（自报）
  • Harness VLA：规划器从固定原语库选调用，冻结 VLA 只做局部接触，探索成功的调用序列存进任务记忆；LIBERO-Pro 同一冻结 π0.5 50.0% → 82.4%（Claude Code），RoboCasa365 30.0% → 57.2%。（自报）
  • HarnessPAI：一次 rollout 内程序固定，多次 rollout 之间改代码；不重训时 LIBERO-PRO 比 π0.5 高 61.6 个点，并报 96.5%。（自报）
  • RoboDojo：42 个仿真加 18 个真机任务的操作策略 benchmark，公开排行榜设 agent 赛道；2026-10-17 仿真榜前两名 WorldScape-R²SI 46.58、EmbodiedEvo 45.08 都在 agent 赛道。（自报）
  • Embodied Agent Arena：10 个前沿 VLM agent 用同一套最小 harness 测几何、空间、规划、操作与可供性五类能力，共 1,000 例；GPT-6 Astra Planning 80.3%、Claude Opus 5.5 Manipulation 47.8%，157 个 Planning 任务有 15 个十个模型全失败。（自报）
  • EmbodiedEvo：在 Playground 场景把物理反馈写成代码 Skills 与 Lessons，冻结后在未见场景执行；RoboDojo-Sim 自跑 Score 44.48、SR 37.82%。（自报）
  • EmbodiedRSI：冻结 VLA 外的 harness 按信息增益与实验成本选下一次物理实验；RoboCasa365 77.0%，真机 SmolVLA 46.0% → 71.3%。（自报）
  • RoboQuest：10 个需靠物理交互取证的移动操作 benchmark；最好的 GPT-6 Astra 成功率 23.2%，失败主要来自缺证据。（自报）
  • RobotWorld：多模态 agent 只用公开的观测与动作工具，在仿真里控制 18 种具身完成 84 个任务，成功由 agent 看不见的评测器判定；项目页未给总分。（自报）
  • Robota-Embed：视觉、语言、动作统一嵌入，检索未来经验片段作上下文；冻结 GPT-6 Astra 加演化出的任务内记忆，ManiSkill 五任务成功率 24% → 68%，策略 token −43.7%。（自报）
  • SenseNova-RoboRSI AMD ✅：冻结权重，用执行反馈改 Harness；RoboDojo-Sim 平均分 60.08、成功率 54.17%，称正在提交官方榜。（自报）
  • WorldScape R²SI：内层 agent 调 Skill 执行，外层 agent 复盘修 Skill 并用执行记录训练动作模型；称 RoboDojo 总榜第一，未给分数。（自报，公司发布稿）
  • Embodied First Exam：coding agent 写代码控制仿真机器人的 benchmark，35 个 suite、2,288 个 test；核心 456 题上 Codex + GPT-6 Astra standard 34%，privileged 77% 而 standard 30%。（自报）
  • PhysicalRSI 1.0：基座改写 harness 生成多个变体、按仿真表现选优继承，π₀.₅ 作为技能之一；RoboDojo-Sim 官方榜 Score 36.27、SR 31.38%。（自报）
  • HexaShell：coding agent 只用一条命令行与三路 RGB 驱动机器人，失败后由第二个 agent 写或修工具；RoboDojo 隐藏种子官方评测 SR 46.9%、进度分 53.2。（第三方，RoboDojo 官方评测）
  • Astranomy：GPT-6 Astra 当原生机器人策略的三种用法；RoboLab-120 上 Codex 会话里的 Agentic Policy 74.8%，每个成功回合约 $36.40。（自报）
  • RoboDoctor：agent 审查、修正或接管冻结 PrismWAM 的动作，按 Warmup 分数选控制方式，再更新干预经验；RoboDojo 54 个任务本地 Refinement 57.10 / 49.44%。（自报）
  • Inspect Robots：把前沿 LLM agent、code-as-policy 与 VLA 接到同一套真机与仿真接口上评测，每次运行留可离线重打分的日志；alpha 阶段，未报评测结果。（自报）
  • RoboRSI AMD ✅：四个 agent 按任务–技能树执行与改技能，失败定位到最早出问题的节点、只改那一支；LIBERO-PRO 297/600（49.5%）对 OpenETA 231/600（38.5%），真机 104 轮家庭清理。（自报）
  • AgenticRoboRL AMD ✅：harness 与 VLA 不动，SFT 加多轮 RL 训练 9B 规划器；RPent / LIBERO-PRO 18.1% → 71.0%，不用外部记忆，同表 Codex（GPT-5.5）带记忆 72.1%。（自报）
  • BiGym 2.0：G1 人形 20 个家务任务，学习策略与冷启动 coding agent 程序走同一全身控制器；九任务均值 π0.5 75%、GPT-6 Astra 65%、Claude Opus 5.5 61%，agent 领先双手 reach、搬运类多数失败。（自报）
  • EmbodiedLab：agent 操作 Franka 自己做 30 个物理与化学实验测隐藏量；原生控制下 Claude Opus 5.5 43.3%，加感知与规划工具最多 +10 点，75–100% 的失败出在与仪器交互。（自报）
  • RoboSkills：五类机器人 agent 工作流打包成每项千行以内的技能包，配首方工具；Agent as Policy 在完整 RoboDojo 上 40.5%，对官方 GPT-6 Astra 22.48%，同任务成本为 Claude Opus 5.5 的 7%。（自报）
  • ZAP（Zero-real Agent Policy）：仿真里 SFT 加多轮 GRPO 训练 27B 模型，在工具 harness 里出绝对末端位姿，训练不用真机数据；真机 10 任务 30 次 96.7%，同 harness 的 GPT-6 Astra 96.7%、Robocurve harness 里 36.7%，MolmoAct2 33.3%。（自报）
  • CaPtain：Qwen3.5-4B 只用 22 个低层原语写代码，先在 GPT-6 Astra 生成的轨迹上 SFT，再用读仿真特权状态的评论家做多轮 RL；LIBERO 留出状态 0% → 55.4% → 73.8%，LIBERO-PRO 78.5%，只在 LIBERO 上训零样本 SimplerEnv WidowX 83.3%、RoboDojo Score 1.7。（自报）

humanoid-tracking

人形机器人如何可靠地跟踪全身动作参考或稀疏控制目标：研究跟踪器的训练方法、参考数据、评测与复现，比较训练覆盖、动作与形态泛化、控制接口及训练代价；方法不限于无模型 RL、学得动力学或可微仿真。操作任务的 RL 训练归 robotics-rl；只研究高层动作生成的按 robot-policy 判定。只使用仿真器不属于 robotics-simulation，对仿真器本身有贡献时两边都挂。

  • 仿真里用可微路线训练人形全身跟踪器：让策略梯度穿过与策略同步训练的世界模型，1 张 H100 训练 3 小时超过 SONIC 的归一化回报；在它上面加评估失败点引导重置，单张 RTX 4090 平均 2.94 分钟到回报 0.82；改为穿过可微仿真器的精确接触梯度、不学世界模型；独立重实现并用形态向量让三台人形共享世界模型与策略，回报与各自专家差 ≤ 0.018，只在 G1 上训的专家换到 T2 存活不到 3%；开源 gym 在同一管线里复现 SuperTrack、SuperMimic 与 BlinkMimic，并把 NDM 当仿真器测吞吐。

robotics-rl

无示教机器人强化学习里，任务配置 / 起始状态怎么采样、奖励与价值从哪来（稀疏或二值奖励、学到的价值模型）的工作，评测这类价值模型的 benchmark，以及在操作任务上从零训练策略的 RL 配方（含穿过学得世界模型或可微仿真的策略梯度）。人形全身跟踪归 humanoid-tracking；在预训练 VLA 上做 RL 微调的配方按 robot-policy 判定；双手灵巧操作的策略、重定向与基准按 dex-manipulation 判定，用无示教 RL 训练双手策略的两边都挂。

robotics-simulation

以机器人仿真本身为研究对象的工作：物理引擎与仿真平台、从真实观测重建或校准仿真场景与物理参数（Real2Sim）、在仿真里批量生成合成数据的流水线，以及检验仿真评测或仿真数据能否代替真机的工作。只在仿真里训练或评测某个策略、只发布仿真任务集而不检验与真机一致性的不算；学到的视频世界模型按 video-world-models 或 action-conditional-world-models 判定。

  • 物理引擎：面向触觉与软体接触的；MuJoCo 4，把可变形体改为与刚体一起隐式求解并加推测接触防穿透。物理引擎只有 MuJoCo 4 给了数字，是对解析解的误差与可用步长，不是与真机的对照。
  • 平台：把 3DGS 场景重建、LLM 生成场景、合成数据与 benchmark 放在一起的；让同一任务配任意臂与末端、内置遥操作与仿真触觉并发布示范数据的；Isaac Lab 上的桌面机械臂–积木受控框架，用 RL 技能加 TAMP 自动生成示范并按 PDDL 判成功。
  • Real2Sim：分别从一张图、人类示范视频和 3D / 4D 采集重建可进仿真的场景，其中一条由编码 agent 调工具并在仿真器里自查；一个数据引擎把第一人称视频与动捕的人手示范，用生成式重定向批量转成 223k 条带接触力标注的灵巧手轨迹。Real2Sim 的物理是否与真机一致多为定性比较。
  • 调参与数据生成：让人和编码 agent 对着视频调多物理仿真的求解器与参数的工具；把仿真数据生成分布当优化对象、用元梯度挑参数再与少量真机示范共训的流水线（四个真机任务全任务成功 52/80 对均匀生成 30/80，专家手调 56/80）；在程序化生成的 1,000 个家庭里合成 300 小时第一人称视觉–语言–全身运动数据、再用生成器与 RL 跟踪器上真机的流水线。
  • 对仿真器本身有贡献的人形跟踪工作：把 MuJoCo 的完整接触动力学与整步 adjoint 做成 GPU kernel，比 MuJoCo Warp 的 adjoint 快 11.5×；把学到的神经动力学模型当仿真器，吞吐是物理仿真的 45.9×。
  • 仿真与真机一致性：单图重建场景里 π0.5 的仿真与真机成功率 Pearson r = 0.887；带一致性标定的 benchmark 里一个基座模型的成功率相关 0.74；平台的 2×2 表里仿真数据训的策略仿真 0.80、真机 0.83；GR00T 2 由 agent 重建的 25 任务数字孪生上 14 个策略 Pearson 0.92。各只用一个模型家族标定。HALO 与 ToyBlocks 各报了自己系统在仿真与真机的成功率（HALO 单任务 91% / 91%，ToyBlocks 原子技能 80.0% / 81.1%、分层拼写 55.5% / 50.0%）。
  • 合成数据替代真机：程序化仿真流水线生成 170 万条示范、完全不用真机数据训练 VLA，零样本真机桌面拾放 79.2% 对 DROID 真机数据策略 39.2%；外部 benchmark 重实现上多数任务为 0。

  • RoboSnap：从一张 RGB 图重建可进仿真的场景，约 20 分钟一个；合成数据与真机数据共训让 π0.5 / π0 真机平均提高 9.0 / 13.4 点，只用真机数据微调的 π0.5 仿真与真机成功率 Pearson r = 0.887。（自报）
