agent-loop

agent 自主提出改动、跑实验、按评估决定接纳的研究或自改进循环，限于不绑定领域的框架或在非机器人任务上验证的工作。

包括在固定评估下搜代码的系统、自主走完研究流程的 agent、评测这类 agent 的环境，以及一个科研工作台。接纳依据有程序化评估器，也有 LLM 判定。全部是自报。

  • Agent Laboratory：LLM agent 走文献综述、实验、写报告三阶段；人评 3.5–4.0 / 10，LLM 自动评审给 6.1、人评 3.8。（自报）
  • AlphaEvolve：LLM 对代码提 diff，按用户写的评估函数进化迭代；找到 4×4 复矩阵 48 次乘法，Borg 调度回收 0.7% 算力。（自报）
  • autoresearch：agent 改单 GPU LLM 训练代码，每次训 5 分钟，val_bpb 变好就保留；不报提升幅度。（自报）
  • RSIAgent：curriculum / actor / verifier 三个 agent 自主练习，经验写进 memory；OSWorld 2.0 71.97 → 78.98。（自报）
  • RSIGym：研究 agent 改另一个系统的数据或 harness 的环境；30 个 Joint run 有 29 个超过初始系统。（自报）
  • Harness²：权重不变，在同一任务上提改动、试跑、按执行对比合成新 harness，经验带到后续任务；单步 WorkBuddy-Bench 最多 +11.5 分。（自报）
  • ScienceDiscovery：本地科研工作台，沙箱跑代码并为每个结果记录来源；不报性能。（自报）
  • SoL-Pi：research agent 读执行 trace 提 harness 改动，按固定的能力与效率门槛筛出四个机制；EdgeBench 上 token 流量比 Pi 少 44.7–49.0%，平均分 42.0 对 44.8。（自报）

agentic-3d

前沿模型写代码或调用工具，生成或重建可进仿真的三维物体与场景，以及评测这件事的基准。以仿真物理与 Real2Sim 为目标的归 robotics-simulation。

一类工作用程序或工具调用生成可仿真的物体和房间，一类评测编码 agent 能否把动态场景写成图形程序，一类按真实文字 / 图 / 视频参考交付可编辑 Blender 工程并跨模型评测，一类把参考视频里的运动换成经解析解对照与独立实现复核的物理求解再渲染，一类把对话 agent 做进 Blender、按提示多步建模与画纹理的创作工具。数字都是作者自报，房间重建没有对照数字，创作工具没有评测数字。

  • Articraft：LLM 对着领域 SDK 写程序生成铰接资产；Articraft-10K 有 245 个类别、超过 1 万个资产。（自报）
  • 4DCodeBench：编码 agent 看视频写图形程序重建动态场景；18 个 agent、200 个任务，运动重建是短板。（自报）
  • Artisan：设计、编码、审查三个智能体加物理验证生成铰接资产；GPT-6 Astra 下单关节碰撞率 1.7%。（自报）
  • AHa-3D：GPT-6 Astra 用工具把室内视频收成 Blender 里可编辑的场景；未给对照数字。（自报）
  • BlenderWorld：13 个前沿模型在 223 个任务上按真实参考交付 Blender 可编辑工程；GPT-6 Astra 融合分 79.9、全 rubric 通过率 42.2%。（自报）
  • Mixar：Blender 5.2 分支内置对话 agent，对场景规划并执行建模、纹理、材质、UV 等多步操作，另有文生 / 图生 3D；AI 后端闭源托管，未给评测数字。（自报）
  • Video 2 Physics：coding agent skill，测量视频运动、换成声明并基准检验过的物理求解，由独立实现复核后烘焙进 Blender；五个示例中独立求解器吻合到 1e-13 量级。（自报）

agentic-infra

给 LLM agent 调用的基础设施组件：检索、记忆等以服务或 SDK 形式接入 agent 的系统。

两个工作：一个元搜索引擎，一个按聊天、生产力、编码分场景的 agent 记忆引擎。都没有评测数字。

  • SearXNG：元搜索引擎，不追踪用户、不建用户画像。（项目 README，无评测）
  • Hy Memory AMD ✅：聊天、生产力、编码三种场景各一条记忆管线，编码场景另存每次修改的真实 diff；README 未报评测数字。（自报）

agentic-robotics

冻结的前沿模型当 agent、在模型外写代码技能 / 程序 / harness 来驱动机器人操作的工作，以及评测这类 agent 的 benchmark。

这个方向的 insight：方向与未解决问题 →

12 个系统让 agent 从执行反馈中把经验沉淀成模型外的技能、程序、记忆或 harness，7 个 benchmark 评测这类 agent，其中 RoboDojo 与 BiGym 2.0 同时评 VLA 等学习策略，EmbodiedLab 让 agent 自己做实验测出隐藏物理量，另有一个把 LLM agent、code-as-policy 与 VLA 接到同一套真机与仿真接口上的评测框架；另有一项实证研究比较前沿模型直接出动作、在 agent 会话里出动作、监督学习策略三种用法；一个工作反过来不动 harness，用教师轨迹 SFT 加多轮 RL 训练 harness 里的小规划器本身；另一个也在 harness 里训练模型本身，用仿真内 SFT 加 GRPO、训练全程不碰真机数据。常见评测是 RoboDojo、LIBERO-Pro、BEHAVIOR-1K、RoboCasa。只有一个系统的分数由 benchmark 方在隐藏种子上复评，其余都是自报。

  • RAX：coding agent 在线探索学任务，再编译成脱离 agent 运行的程序；未见布局平均成功率随探索 4 → 128 回合从 25% 升到 79%，编译后执行快 100× 以上。（自报）
  • ASPIRE：按执行 trace 修 code-as-policy 程序，验证过的修复进技能库；Claude Opus 5.5 下 LIBERO-Pro 平均 99%。（自报）
  • HarnessPAI：一次 rollout 内程序固定，多次 rollout 之间改代码；不重训时 LIBERO-PRO 比 π0.5 高 61.6 个点，并报 96.5%。（自报）
  • RoboDojo：42 个仿真加 18 个真机任务的操作策略 benchmark，公开排行榜设 agent 赛道；2026-10-17 仿真榜前两名 WorldScape-R²SI 46.58、EmbodiedEvo 45.08 都在 agent 赛道。（自报）
  • Embodied Agent Arena：10 个前沿 VLM agent 用同一套最小 harness 测几何、空间、规划、操作与可供性五类能力，共 1,000 例；GPT-6 Astra Planning 80.3%、Claude Opus 5.5 Manipulation 47.8%，157 个 Planning 任务有 15 个十个模型全失败。（自报）
  • EmbodiedEvo：在 Playground 场景把物理反馈写成代码 Skills 与 Lessons，冻结后在未见场景执行；RoboDojo-Sim 自跑 Score 44.48、SR 37.82%。（自报）
  • EmbodiedRSI：冻结 VLA 外的 harness 按信息增益与实验成本选下一次物理实验；RoboCasa365 77.0%，真机 SmolVLA 46.0% → 71.3%。（自报）
  • RoboQuest：10 个需靠物理交互取证的移动操作 benchmark；最好的 GPT-6 Astra 成功率 23.2%，失败主要来自缺证据。（自报）
  • RobotWorld：多模态 agent 只用公开的观测与动作工具，在仿真里控制 18 种具身完成 84 个任务，成功由 agent 看不见的评测器判定；项目页未给总分。（自报）
  • Robota-Embed：视觉、语言、动作统一嵌入，检索未来经验片段作上下文；冻结 GPT-6 Astra 加演化出的任务内记忆，ManiSkill 五任务成功率 24% → 68%，策略 token −43.7%。（自报）
  • SenseNova-RoboRSI AMD ✅：冻结权重，用执行反馈改 Harness；RoboDojo-Sim 平均分 60.08、成功率 54.17%，称正在提交官方榜。（自报）
  • WorldScape R²SI：内层 agent 调 Skill 执行，外层 agent 复盘修 Skill 并用执行记录训练动作模型；称 RoboDojo 总榜第一，未给分数。（自报，公司发布稿）
  • Embodied First Exam：coding agent 写代码控制仿真机器人的 benchmark，31 个 suite、1,090 个任务；核心 449 题上 Codex + GPT-6 Astra 32.7%，privileged 75.5% 而 standard 33.8%。（自报）
  • PhysicalRSI 1.0：基座改写 harness 生成多个变体、按仿真表现选优继承，π₀.₅ 作为技能之一；RoboDojo-Sim 官方榜 Score 36.27、SR 31.38%。（自报）
  • HexaShell：coding agent 只用一条命令行与三路 RGB 驱动机器人，失败后由第二个 agent 写或修工具；RoboDojo 隐藏种子官方评测 SR 46.9%、进度分 53.2。（第三方，RoboDojo 官方评测）
  • Astranomy：GPT-6 Astra 当原生机器人策略的三种用法；RoboLab-120 上 Codex 会话里的 Agentic Policy 74.8%，每个成功回合约 $36.40。（自报）
  • RoboDoctor：agent 审查、修正或接管冻结 PrismWAM 的动作，按 Warmup 分数选控制方式，再更新干预经验；RoboDojo 54 个任务本地 Refinement 57.10 / 49.44%。（自报）
  • Inspect Robots：把前沿 LLM agent、code-as-policy 与 VLA 接到同一套真机与仿真接口上评测，每次运行留可离线重打分的日志；alpha 阶段，未报评测结果。（自报）
  • RoboRSI：四个 agent 按任务–技能树执行与改技能，失败定位到最早出问题的节点、只改那一支；LIBERO-PRO 297/600（49.5%）对 OpenETA 231/600（38.5%），真机 104 轮家庭清理。（自报）
  • AgenticRoboRL AMD ✅：harness 与 VLA 不动，SFT 加多轮 RL 训练 9B 规划器；RPent / LIBERO-PRO 18.1% → 71.0%，不用外部记忆，同表 Codex（GPT-5.5）带记忆 72.1%。（自报）
  • BiGym 2.0：G1 人形 20 个家务任务，学习策略与冷启动 coding agent 程序走同一全身控制器；九任务均值 π0.5 75%、GPT-6 Astra 65%、Claude Opus 5.5 61%，agent 领先双手 reach、搬运类多数失败。（自报）
  • EmbodiedLab：agent 操作 Franka 自己做 30 个物理与化学实验测隐藏量；原生控制下 Claude Opus 5.5 43.3%，加感知与规划工具最多 +10 点，75–100% 的失败出在与仪器交互。（自报）
  • ZAP（Zero-real Agent Policy）：仿真里 SFT 加多轮 GRPO 训练 27B 模型，在工具 harness 里出绝对末端位姿，训练不用真机数据；真机 10 任务 30 次 96.7%，同 harness 的 GPT-6 Astra 96.7%、Robocurve harness 里 36.7%，MolmoAct2 33.3%。（自报）

agentic-skills

可安装到 coding agent 里、以 SKILL.md 或插件交付的任务流程：把一类任务写成 agent 按步骤执行的指令、检查器与脚本。运行中由 agent 自己改写并按评估接纳的循环归 agent-loop；驱动机器人的代码技能归 agentic-robotics；以服务或 SDK 接入的检索与记忆归 agentic-infra。

三个技能包都没有对自身输出的评测。一个用深上下文起草规格、用没有先前对话的子 agent 找漏洞，人批准后才写代码；一个把材料做成整页图片再组装成 pptx，生成前等人确认样张；一个按 60 篇获奖论文拟合的规则起草论文，缺的数字留成占位。依据都是项目 README 的自述。

  • Elephant-Goldfish Model：Elephant 带项目上下文起草规格，Goldfish 在新子 agent 里审，人批准后才实现；README 称数千名 Google 工程师在用，未给评测。（项目 README，无评测）
  • Best-Paper-Writing：按 60 篇获奖论文的写法起草论文并跑检查器；风格规则在 55 篇上拟合、5 篇留出，留出分数未说明。（项目 README，无评测）
  • Codex PPT：先确认大纲、风格和一页样张，再逐页生成整页图片并组装 pptx；未报评测数字。（项目 README，无评测）

dex-manipulation

双手灵巧操作的研究方向：跨物体与跨参考的通用双手策略、人手示范到机器人手的重定向，以及评测这类策略的仿真基准与泛化轴。

五个工作：两个仿真 benchmark，一个覆盖 12 种灵巧手并带视触觉接口与不变性 / 等变性泛化轴，一个 66 个任务分出只用于泛化的 Transfer-16；一个跟踪人类双手示范的参考条件策略；一条从人类视频重建仿真场景、按接触力旋量把人手示范转成 RL 奖励的流水线，附 4,739 个任务的自建基准；一个不依赖物体网格、按接触力目标重定向人手示范的框架。两个 benchmark 上最好的学习策略都不到 30%（Bench2Dex GR00T N1.5 28.3%、HandsOn OpenWAM 29.1%），工具使用与精密装配只有 2–3%；示范跟踪类方法在自己的任务上高得多（DONIC 未见轨迹 86.79%，CHORD 1,831 个任务平均 82.12%）；接触保持上 CARD 在 SHARPA Wave 的接触帧是 43.1–77.7%，运动学重定向低于 10%。DONIC、CHORD 与两个 benchmark 只在仿真里给成功率，CARD 的真机是 30 次开环回放（只跟位置 4/30，加触觉跟踪 25/30）。全部是自报。

  • Bench2Dex：12 种灵巧手、26 个双手任务的仿真视触觉 benchmark，每个泛化通道 50 次 rollout；四通道平均稳定成功率 GR00T N1.5 28.3%、π0.5 20.3%、ACT 18.0%、DP 7.1%，触觉接口未与实体传感器校准。（自报）
  • HandsOn：Isaac Sim 上 ROKAE–Wuji 双手平台的 66 个任务、18,000 条人类演示；Core-50 最好的 OpenWAM 29.1%，GPT-6 Astra 用 move_eef 零微调合计 4.4%。（自报）
  • DONIC：一个参考条件策略用两只 Wuji 手跟踪人类双手示范，单一 checkpoint 零微调未见轨迹 86.79%、未见物体 57.32%，比双手适配的 DexTrack / Dexplore 高 77.36 / 45.73 点；只在仿真评。（自报）
  • Video to Data (V2D)：人类示范视频 → 重建网格与 6-DoF 位姿 → 人手重定向到灵巧手 → Isaac Lab 里按接触力旋量奖励训 RL（CHORD）；自建 4,739 任务中评 1,831 个平均 82.12%，AUC 0.918 对 Spider 0.804，真机只有演示。（自报）
  • CARD：不依赖物体网格，把接触力目标重定向到 SHARPA Wave；接触帧 43.1–77.7%（视频 / 手套加动捕 / GRAB），运动学基线低于 10%；真机同一轨迹 30 次，触觉跟踪 25 次成功、只跟位置 4 次。（自报）

jev

输入状态与候选项、直接返回选择及其概率的 System 1 决策模型与服务。

一个训练与部署框架、一个推理服务器。agent 循环里的收益只有单次录制演示。全部是自报。

  • JevAny：决策模型的开源训练与部署框架；27B 模型 Transfer 86.04%、JevBench 90.04%，ECE 0.026。（自报）
  • OpenJev：在扩散模型上只遮答案槽、一次前向读出每个选项概率的决策服务器；短状态 p50 30 ms，本身没有准确率评测。（自报）

llm-foundation-models

agent 可用的前沿基础模型发布。

5 个通用 agent / 编码模型、1 个物理推理基座。各家基准版本与 harness 不一，数字跨来源不可直接比。全部是自报。

  • GLM-5.3-Flash：智谱首个原生多模态 GLM-5 模型，320B 总参、18B 激活，线性加稀疏注意力；DeepSWE v1.1 63.4。（自报）
  • Muse Spark 1.3：Meta 面向长程 agent 与编码的模型，1M 上下文；DeepSWE v1.1 75.4、Terminal-Bench 2.1 88.8。（自报）
  • DeepSeek-V4.1-Flash：552B MoE、原生视觉，KV cache 为上一代 1/4；未公布基准数字。（自报）
  • MiMo-V2.6：小米开源全模态系列，加大可验证任务上的 RL 算力；held-out DeepSWE v1.1 Pro 58.4 → 72.57。（自报）
  • Gemini 4 Argon：Google 物理推理基座；仿真造数据后真机成功率 56% → 75%，未给评测次数。（自报，博客）
  • DeepSeek-V4.1-Flash-1017：V4.1-Flash 小版本更新，输出更短；Terminal-Bench 4.0 31.2 → 42.3。（自报）

robot-policy

训练出来、给出机器人动作的模型：直接输出动作的 VLA 与通用策略，在同一模型里联合预测未来（画面、深度或隐变量）与动作的世界动作模型，以及在学到的世界模型里规划出动作的控制模型；关注跨具身数据混合、动作表征与预训练配方、预测未来对出动作的作用，以及对这类模型的机制分析。冻结前沿模型加 harness 驱动的归 agentic-robotics。

十一个工作按预测不预测未来分成四类。不预测、直接出动作的四个：三个多具身 VLA 家族，一个把操作、导航与轨迹预测放进同一动作空间，一个公开五个具身的数据与权重，一个开源权重与训练推理流程；一个让预训练 VLM 零样本输出连续动作的接口。先预测未来隐变量再出动作的两个，推理单元是离散的动作词或运动词元，其中一个用想象与真实未来的一致度做强化奖励，让无动作标注的人类视频也能训练。在同一模型里联合生成未来画面（或深度、技能代码）与动作的三个，其中一个的未来画面只在训练时作监督；另有一个不建新模型，在四个已有 WAM 上量测 test-time 选择的可选中余量。最后一个不训策略，在 12 种具身数据训的隐空间世界模型里按目标图像规划动作，真机上与 VLA 指令形式不同、不算直接可比。常见对照是 π0.5 与 GR00T 系列，常见评测是 LIBERO 与 RoboTwin；真机评测各用自己的任务，每任务 15–50 次或未给次数。全部是自报。

  • Qwen-VLA：Qwen3.5-4B 骨干加 1.15B DiT 流匹配动作解码器，操作、导航、轨迹预测共用一个动作空间、一次联合训练；ALOHA 真机分布内 83.6% 对 π0.5 71.6%，分布外 76.9% 对 41.5%，去掉大规模动作预训练降到 48.5% / 36.2%。（自报）
  • OpenDM（DM0.5）：DM0.5 的开放权重与训练 / 推理流程，沿用 DM0 的 native embodied modeling；LIBERO 99.0%、RoboTwin2.0 clean 93.6%（π0.5 96.9 / 82.7），RoboDojo-Sim Score 24.90 对 11.41。（自报）
  • MolmoAct2：Molmo2-ER 具身推理 VLM 接流匹配动作专家，公开五个具身的数据、tokenizer、权重与训练代码；LIBERO 微调 97.2%，零样本真机 OOD 五任务 87.1%，单张 H100 55.79 Hz。（自报）
  • EASG：把 TCP 动作坐标系投到腕部画面，让预训练 VLM 用文本直接输出连续动作；Qwen3.8-27B 零样本 6 个真机任务 79.4%，π0.5 用 30 条示范为 76.1%，去掉坐标系投影降到 0%。（自报）

robotics-rl

无示教机器人强化学习里，任务配置 / 起始状态怎么采样、奖励从哪来（稀疏或二值奖励、学到的价值模型）的工作，以及评测这类价值模型的 benchmark。

robotics-simulation

以机器人仿真本身为研究对象的工作：物理引擎与仿真平台、从真实观测重建或校准仿真场景与物理参数（Real2Sim）、在仿真里批量生成合成数据的流水线，以及检验仿真评测或仿真数据能否代替真机的工作。只在仿真里训练或评测某个策略、只发布仿真任务集而不检验与真机一致性的不算；学到的视频世界模型归 video-world-models。

这个方向的 insight：方向与未解决问题 →

七个工作：两个平台，一个是面向触觉与软体接触的物理引擎，一个把 3DGS 场景重建、LLM 生成场景、合成数据与 benchmark 放在一起；三条 Real2Sim 流水线分别从一张图、人类示范视频和 3D / 4D 采集重建可进仿真的场景，其中一条由编码 agent 调工具并在仿真器里自查；一个工具让人和编码 agent 对着视频调多物理仿真的求解器与参数；一个带仿真与真机一致性标定的 benchmark。三个工作量了仿真与真机的一致性：单图重建场景里 π0.5 的仿真与真机成功率 Pearson r = 0.887，benchmark 里一个基座模型的成功率相关 0.74，平台的 2×2 表里仿真数据训的策略仿真 0.80、真机 0.83；三者各只用一个基座模型标定。Real2Sim 的物理是否与真机一致多为定性比较，物理引擎没有给数字。全部是自报。

video-world-models

构建可交互、长程生成的视频世界模型的工作：其数据整理、latent 表示、因果训练与蒸馏方法，以及衡量生成是否跟随控制信号、能否在想象中替代真机评测策略的评测。

六个构建工作分别给出数据与训练配方、可在想象中闭环评测策略的动作条件模型、按下游策略回报训练世界模型的目标、用一套条件化同时接入力、相机、手与机器人姿态的统一动作接口、一个原生同时生成环境音与人物对话、由 Gemini 在环实时拆步骤推进场景的闭源预览，以及一个用统一模型接多轮文本与键盘 / 相机轨迹、分段因果生成的开放模型；两个 benchmark，一个拿同一段动作下的预测视频与真机执行比、长回合上各模型分数明显下降，一个是自建的 280 例交互能力人工成对评测。构建类工作没有共同的定量对照：SolarWM 只给定性 rollout，Ctrl-World 的 README 不给数字，DRILL 只在自己的五个仿真器上对照像素目标，Genie 4 只有博客演示、一个数字都没给，Hy-Nomas 只在自建 benchmark 上比人工胜率。全部是自报。
