方向与工作Insights

以下是 insight agent 对各方向的判断：下一个值得做的方向与未解决的问题。它们是判断，不是证据；证据见方向与工作里对应的 lens。

agentic-robotics

冻结的前沿模型当 agent、在模型外写代码技能 / 程序 / harness 来驱动机器人操作的工作，以及评测这类 agent 的 benchmark。

Directions

Test whether state estimation, not more reasoning, closes the privileged–standard gap

  • Why: The top agent in Embodied First Exam solves 75.5% with privileged simulator state but 33.8% through the robot API. In RoboQuest, 43–46% of failures are missing evidence, while the execution skills pass 72–81% once the hidden information is given. Astranomy lifts Direct control from 19.3% to 72.7% by writing gripper and camera geometry into the prompt, and HexaShell builds its own dual-view triangulation tool. All self-reported except HexaShell's official score.
  • Gap: No work isolates a perception layer: nobody gives the same agent estimated object poses as a tool and measures how much of the privileged–standard gap closes.
  • First experiment: On the Embodied First Exam standard split, add a pose-estimation and multi-view triangulation tool to the agent's API; report, per suite, the fraction of the 75.5% → 33.8% gap recovered.

Treat the agent loop as a data engine for a cheap policy

  • Why: Agent control is expensive: Astranomy spends 30.9M tokens ($36.40) per successful Agentic episode against $1.96 for Direct. Works that amortize the agent report large gains: RAX compiles exploration into programs that run 103–241× faster; HarnessPAI fine-tunes π0.5 on its collected trajectories, 34.9% → 73.7% on LIBERO-PRO; SenseNova-RoboRSI trains a 27B model on verified traces (RoboCasa365 26.0% → 46.5%, output tokens −73.3%); WorldScape R²SI trains its action model on execution records. All self-reported.
  • Gap: No work compares the three amortization targets (compiled program, fine-tuned VLA, distilled VLM) under one trace budget on held-out layouts, with cost per success reported.
  • First experiment: From one agent run's verified traces, build all three and evaluate them on the same held-out RoboDojo layouts; report success rate and dollars per success.

Hand contact-rich steps to a learned policy

  • Why: Agents are weakest where contact precision matters: HexaShell scores 32.0% on RoboDojo Precision against 81.0% on Memory (official), and EmbodiedEvo reports fine insertion and liquid handling as still hard. Hybrids already call VLAs as skills (HarnessPAI, PhysicalRSI 1.0, SenseNova-RoboRSI) or let the agent supervise a policy, but RoboDoctor picks the controller per task from a fixed warmup threshold, and Astranomy's Orchestrated mode (66.5%) trails pure Agentic (74.8%).
  • Gap: No work reports per-capability results showing where a handoff to a learned policy helps.
  • First experiment: On RoboDojo, compare agent-only against agent-plus-VLA-skill per capability dimension (Precision, Long-horizon, Memory), same agent and seeds.

Open problems

  • Held-out discipline in self-improving loops: HarnessPAI's 50-seed LIBERO-PRO score includes the 15 seeds its programs evolved on; PhysicalRSI 1.0 does not say whether its select-on-eval set is disjoint from the leaderboard; WorldScape R²SI revises skills on the same layout; RoboDoctor keeps the best of several runs. Of the 17 works, only HexaShell was re-evaluated by the benchmark owner on hidden seeds.
  • Knowing whether the task is done: RoboQuest agents decide when to submit, and 23–31% of their failures are wrong decisions; ASPIRE names success detection and safe reset as what still blocks autonomous real-robot learning; Embodied First Exam probes its verifiers with an agent trying to pass without doing the task. One capability blocks both evaluation and real-world improvement loops.
  • Real-robot evidence is thin: EmbodiedRSI evolves in simulation and deploys zero-shot on five SO-101 tasks; RAX relies on operator resets; SenseNova-RoboRSI shows real-robot demos without success rates; RoboDojo's real-robot leaderboard has one visible entry.

robotics-simulation

以机器人仿真本身为研究对象的工作：物理引擎与仿真平台、从真实观测重建或校准仿真场景与物理参数（Real2Sim）、在仿真里批量生成合成数据的流水线，以及检验仿真评测或仿真数据能否代替真机的工作。只在仿真里训练或评测某个策略、只发布仿真任务集而不检验与真机一致性的不算；学到的视频世界模型归 video-world-models。

Landscape

Simulation is put to three uses, and two lines of work build what those uses run on. Every number below is self-reported, and no two works in the lens share a benchmark.

  • Data engine: generate demonstrations to co-train or fine-tune a policy. RoboSnap co-trains π0.5 on real plus synthetic data (+9.0 points on the real robot); Genie Sim's sim-only π0.5 reaches 0.83 on the real robot against 0.75 for real data; SceneAgent reaches 88% real with staged sim-only fine-tuning; Video to Data (V2D) turns human video into RL experts whose rollouts fine-tune GR00T N1.7.
  • Evaluator: stand in for real-robot evaluation. X2Real (sim–real progress correlation 0.84, success 0.74), RoboSnap (Pearson r = 0.887), Genie Sim (sim–real difference under 10%). Learned simulators compete for this role: Ctrl-World rolls policies out in imagination, and WorldOracle shows video world models degrading as episodes lengthen.
  • RL environment for counterfactual rollouts: massively parallel physics RL with sparse or binary rewards (SGS at 1M environments, AlphaNIST, DexSafe, CHORD in Video to Data (V2D)), or a learned model in place of the simulator (SuperMimic backpropagates through a world model, DRILL trains the world model on imagined policy return).
  • Building the sim (Real2Sim): from one image (RoboSnap), human video (Video to Data (V2D)) or 3D / 4D captures (SceneAgent). The building is moving to coding agents that inspect and repair their own output (SceneAgent, RoboSimStudio, LLM-generated scenes in Genie Sim); on 4DCodeBench most agents still write motion as hand-tuned curves rather than simulating it.
  • Physics for contact and soft bodies: Project SuperDex's contact-first engine and RoboSimStudio's explicitly tunable solvers; neither reports fidelity numbers.

Directions

Make sim–real disagreement the verifier of agent-built sims

  • Why: Agentic builders check themselves against geometry or their own visual review. SceneAgent reports F1 at 1 cm (9.51% → 60.75% with its skills) and leaves physical parameters unvalidated; RoboSimStudio judges consistency qualitatively, yet its one real-robot failure (a holder that moved in reality but was fixed in sim) was enough for the agent to correct the constraint. Sims used as evaluators are calibrated separately and after the fact (X2Real, RoboSnap).
  • Gap: No work in the library feeds per-episode sim–real outcome disagreement back to the building agent and reports agreement after each repair round.
  • First experiment: On one RoboSnap-style scene, run the same policy for 50 episodes on the real robot and in the sim; give the coding agent the paired videos and outcomes as its verifier; report the success-rate gap and per-episode agreement after each repair round, against a geometry-only verifier.

Find out why more simulated demonstrations stop helping on the real robot

  • Why: In SceneAgent, a VLA fine-tuned on sim-only pick-and-place data peaks at 48% real success with 40 episodes and falls to 12% at 4k, while sim success keeps rising; staged training on three datasets then reaches 88%. RoboSnap reports its gain at one mixing ratio and Genie Sim at 500–1,500 sim episodes; neither gives a scaling curve.
  • Gap: At a fixed episode count, no work separates the candidate causes: one scripted expert's homogeneity, the rendering gap, or the physics gap.
  • First experiment: At 4k episodes on SceneAgent's eggplant task, train on (a) one scripted expert, (b) varied and noise-injected experts, (c) the same trajectories re-rendered over a real-captured background, (d) randomized physics; report real success for each.

Pit a reconstructed physics twin against a learned world model as the RL environment for the same scene

  • Why: Physics-sim RL transfers on contact tasks when evaluated at scale (DexSafe: 95.2% on 4,800 unseen real targets). Learned models train fast (SuperMimic beats SONIC's return in 3 H100-hours) and can be tuned for policy return (DRILL: +13.1 points over WMPO in simulation), but WorldOracle shows Cosmos 3 falling from 53.99 to 26.60 as episodes lengthen. Real2Sim now builds a physics twin from one image in about 20 minutes (RoboSnap).
  • Gap: No work in the library RL-fine-tunes the same policy in a physics twin and in a world model of the same scene and compares real-robot success.
  • First experiment: From one capture, build a RoboSnap twin and a Ctrl-World-style action-conditioned model; RL-fine-tune π0.5 with the same binary success reward in each; report real success, wall-clock time and GPU hours.

Open problems

  • Sim evaluation is calibrated on one policy per platform: X2Real uses Wall-OSS-0.5, RoboSnap π0.5, and Genie Sim π0.5 on 8 tasks; X2Real also reports a clear real2sim gap on precision tasks. Whether these sims rank different policies the way the real robot does is not reported for them.
  • Physical parameters stay unverified: SceneAgent estimates them from semantics and VLM priors and calls the inverse problem ill-posed; RoboSimStudio compares with video qualitatively; Project SuperDex gives no numbers.
  • No shared yardstick for the real value of sim data: RoboSnap (10 tasks), Genie Sim (8 tasks) and SceneAgent (one pick-and-place task) each choose their own tasks, ratios and robots, so their pipelines cannot be compared.
